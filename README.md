# تطبيق هُمام | Humam App 📱

تطبيق إسلامي وخدمي متكامل مبني باستخدام **Flutter** وقواعد بيانات **Firebase**، يقدم تجربة مستخدم سلسة مع دعم قراءة القرآن الكريم، أوقات الصلاة، وخدمات إضافية.

---

## ✨ المميزات الرئيسية
- 📖 **المصحف الشريف:** عرض القرآن الكريم بخطوط واضحة وتجويد مخصص.
- 🕌 **مواقيت الصلاة والأذان:** تنبيهات دقيقة لجميع الصلوات.
- ⚡ **أداء عالي ومعمارية نظيفة:** مبني على مبادئ Clean Architecture و Feature-First لسهولة التوسع والتطوير.
- ☁️ **المزامنة السحابية:** تكامل كامل مع خدمات Google Firebase (Firestore & Cloud Messaging).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)
- **Framework:** Flutter (Dart)
- **Backend & Database:** Firebase Firestore
- **Architecture:** Feature-First / Clean Structure
- **Assets & Media:** Custom Typography & Audio Assets
